## Integration Issues Found

### Issue 1: Environment Variable Not Loaded Initially ✅ RESOLVED

**Problem:** `N8N_API_KEY` was not available in Python backend container after editing `.env` file

**Cause:** Docker containers don't automatically reload environment variables from updated `.env` files

**Solution:** Ran `docker-compose up -d --force-recreate backend-python` to rebuild container with new env vars

**Prevention:** Document that `.env` changes require container recreation

---

### Issue 2: TypeScript Compilation Warnings ⚠️ NON-BLOCKING

**Problem:** Pre-existing TypeScript errors in other modules (auth, services)

**Impact:** None on n8n monitoring functionality - n8n-monitoring files compile without errors

**Status:** Non-blocking for this story; can be addressed in separate tech debt ticket

**Files Affected:** auth.middleware.ts, user-registration.service.ts (not related to Story 2.2.1)
