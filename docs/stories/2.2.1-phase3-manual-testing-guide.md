### Step 2: Configure Authentication (5 minutes)

**Important:** All HTTP Request nodes in the workflow need authentication credentials.

1. **Create HTTP Header Auth Credential:**
   - In n8n UI, click **Credentials** (left sidebar)
   - Click **Add Credential**
   - Select **HTTP Header Auth**
   - Configure:
     - **Name:** `backend-api-auth`
     - **Header Name:** `Authorization`
     - **Header Value:** `Bearer n8n-integration-test-key-2025`
   - Click **Save**

2. **Apply Credential to HTTP Request Nodes:**

   For EACH of these 7 nodes, you need to add the credential:
   - ✓ Check for Duplicates
   - ✓ Extract Document Text
   - ✓ Analyze Chunking Strategy
   - ✓ Chunk Document
   - ✓ Generate Embeddings
   - ✓ Store Chunks in Database
   - ✓ Update Document Status nodes (all 3 variants)

   **For each node:**
   1. Click the node in the canvas
   2. Scroll to **Authentication** section
   3. Enable **Authentication**
   4. Select **Predefined Credential Type**
   5. Choose **HTTP Header Auth**
   6. Select credential: `backend-api-auth`
   7. Click **Save** (bottom of panel)

## Common Issues & Solutions

### Issue 1: Workflow won't import

**Symptoms:** Error message when importing JSON file

**Solutions:**
- Verify JSON file is valid (check for syntax errors)
- Try importing via n8n CLI instead of UI
- Check n8n version compatibility
- Restart n8n service: `docker-compose restart n8n`

### Issue 2: Authentication fails on HTTP nodes

**Symptoms:** 401/403 errors in workflow execution

**Solutions:**
- Verify API key matches `.env` file: `N8N_API_KEY=n8n-integration-test-key-2025`
- Check credential is selected in ALL HTTP Request nodes
- Test API endpoint directly:
  ```bash
  curl -X GET http://py.tip.localhost/api/n8n/health \
    -H "Authorization: Bearer n8n-integration-test-key-2025"
  ```

### Issue 3: Webhook returns 404

**Symptoms:** `curl` to webhook returns "Not Found"

**Solutions:**
- Verify workflow is **Active** (toggle on)
- Check webhook path matches: `/webhook/document-processing`
- Restart n8n: `docker-compose restart n8n`
- Check n8n logs: `docker-compose logs n8n --tail=50`

### Issue 4: Text extraction fails

**Symptoms:** Workflow stops at "Extract Document Text" node

**Solutions:**
- Check backend-python is running: `docker-compose ps backend-python`
- Verify file content is valid base64
- Test extraction endpoint directly:
  ```bash
  curl -X POST http://py.tip.localhost/api/n8n/extract-text \
    -H "Authorization: Bearer n8n-integration-test-key-2025" \
    -H "Content-Type: application/json" \
    -d '{"document_id":"test","file_content_base64":"dGVzdA==","mime_type":"text/plain"}'
  ```

### Issue 5: Embeddings generation fails

**Symptoms:** Node fails with "Model not available"

**Solutions:**
- Check Ollama is running:
  ```bash
  curl http://host.docker.internal:11434/api/tags
  ```
- Verify `nomic-embed-text` model is installed:
  ```bash
  ollama list | grep nomic
  ```
- Pull model if missing:
  ```bash
  ollama pull nomic-embed-text
  ```

### Issue 6: Frontend monitoring shows no data

**Symptoms:** Empty metrics cards and table

**Solutions:**
- Verify backend-node is running: `docker-compose ps backend-node`
- Check API endpoint:
  ```bash
  curl -H "x-auth-bypass: true" http://api.tip.localhost/api/knowledge/n8n/metrics
  ```
- Ensure at least one workflow execution has completed
- Check browser console for errors (F12)
