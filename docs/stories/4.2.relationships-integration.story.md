## Story
**As a** Government Program Director or Program Manager,
**I want** to assign stakeholders to Products/Programs, categorize transitions to Products/Programs, and link Products/Programs to Business Operations,
**so that** I can track who is responsible for each product/program, understand which transitions are related to which products, and maintain clear organizational relationships.

## Acceptance Criteria
1. Database schema updated to support many-to-many relationship between Products/Programs and Users (stakeholders)
2. Database schema updated to support relationship between Transitions and Products/Programs (categorization)
3. Database schema updated to support relationship between Products/Programs and Business Operations
4. Backend API provides endpoints to assign/remove stakeholders to/from Products/Programs
5. Backend API updated to support assigning Transitions to Products/Programs
6. Backend API provides endpoints to link Products/Programs to Business Operations
7. Frontend displays list of assigned stakeholders on Product/Program detail page
8. Frontend provides UI to add/remove stakeholders with user search/selection
9. Frontend displays list of related transitions on Product/Program detail page
10. Frontend provides UI to assign existing transitions to a Product/Program
11. Frontend allows categorization of transitions from transition detail page
12. Migration script successfully updates existing transitions to allow categorization
13. Business Operations relationship is displayed and manageable in UI
14. All relationships respect role-based access control
15. Integration tests verify all relationship operations
16. No regression in existing Transitions, Business Operations, or User Management features

### Data Model Updates

**ProductProgramStakeholder Junction Model:**
```prisma
model ProductProgramStakeholder {
  id               String          @id @default(uuid())
  productProgramId String
  userId           String
  role             String?         @db.VarChar(100) // e.g., "Program Lead", "Technical Lead"
  assignedAt       DateTime        @default(now())
  assignedBy       String

  productProgram   ProductProgram  @relation(fields: [productProgramId], references: [id], onDelete: Cascade)
  user             User            @relation(fields: [userId], references: [id], onDelete: Cascade)
  assignedByUser   User            @relation("AssignedStakeholders", fields: [assignedBy], references: [id])

  @@unique([productProgramId, userId])
  @@map("product_program_stakeholders")
}
```

### API Specifications

**Stakeholder Endpoints:**

1. **POST /api/business-operations/products-programs/:id/stakeholders**
   - Request: `{ userId: string, role?: string }`
   - Response: `{ success: true, data: ProductProgramStakeholder }`
   - Permissions: Admin, Gov Program Director, Gov Program Manager

2. **GET /api/business-operations/products-programs/:id/stakeholders**
   - Response: `{ success: true, data: ProductProgramStakeholder[] }`
   - Permissions: All authenticated users

3. **PUT /api/business-operations/products-programs/:id/stakeholders/:userId**
   - Request: `{ role: string }`
   - Response: `{ success: true, data: ProductProgramStakeholder }`
   - Permissions: Admin, Gov Program Director, Gov Program Manager

4. **DELETE /api/business-operations/products-programs/:id/stakeholders/:userId**
   - Response: `{ success: true, message: "Stakeholder removed" }`
   - Permissions: Admin, Gov Program Director, Gov Program Manager

**Transition Categorization Endpoints:**

5. **PUT /api/transitions/:id/product-program**
   - Request: `{ productProgramId: string }`
   - Response: `{ success: true, data: Transition }`
   - Permissions: Admin, Gov Program Director, Gov Program Manager

6. **DELETE /api/transitions/:id/product-program**
   - Response: `{ success: true, message: "Product/Program removed from transition" }`
   - Permissions: Admin, Gov Program Director, Gov Program Manager

7. **GET /api/business-operations/products-programs/:id/transitions**
   - Response: `{ success: true, data: Transition[] }`
   - Permissions: All authenticated users

**Business Operations Linking Endpoints:**

8. **PUT /api/business-operations/products-programs/:id/business-operation**
   - Request: `{ businessOperationId: string }`
   - Response: `{ success: true, data: ProductProgram }`
   - Permissions: Admin, Gov Program Director

9. **DELETE /api/business-operations/products-programs/:id/business-operation**
   - Response: `{ success: true, message: "Business operation unlinked" }`
   - Permissions: Admin, Gov Program Director
